# A Diagnostic Protocol for Separating Leakage from Complementary Signal in Metadata-Augmented Image Classification

This repository contains the Jupyter notebooks and experimental workflow associated with the research study **“A Diagnostic Protocol for Separating Leakage from Complementary Signal in Metadata-Augmented Image Classification.”**

The project investigates whether performance improvements from metadata-augmented image classification reflect label leakage, spatial contamination, or useful predictive information that a fusion architecture may fail to exploit.

## Research Objectives

The study addresses four research questions:

1. How can label leakage be distinguished from complementary signal using an independently validated diagnostic protocol?
2. Does random evaluation splitting inflate performance in geotagged image classification compared with spatially blocked evaluation?
3. Does a small or null metadata-fusion improvement imply that metadata contains little predictive information, or that the fusion architecture cannot extract it?
4. What architectural and optimization factors may explain differences between metadata information available to a classifier and information extracted by a neural fusion model?

## Methodology

The experimental protocol combines:

- Paired-task evaluation using a leakage positive control and a contrasting scene-classification task.
- Functional-dependency and conditional-entropy analysis.
- Metadata-only classifiers and majority-class baselines.
- Image-only, metadata-only, and image–metadata fusion comparisons.
- Synergy analysis and metadata permutation controls.
- Random versus spatially blocked evaluation splits.
- Metadata-encoder and modality-dropout ablations.
- A matched-split gradient-boosted-tree baseline.
- Statistical comparisons and result visualizations.

### Experimental Tasks

**Task A — Continent classification:** The target is derived from geographic information. Country metadata can determine the continent label, providing a positive control for target-determining metadata.

**Task B — Scene classification:** Twelve scene categories are generated using a frozen CLIP teacher and confidence-margin filtering. This task investigates metadata that may be predictive without directly determining the target.

## Key Experimental Details

- **Image representation:** Frozen ImageNet-pretrained ResNet50.
- **Scene-label generation:** Frozen CLIP teacher with prompt ensembling and confidence-margin filtering.
- **Scene taxonomy:** 12 categories, including beach, desert, farmland, forest, indoor, industrial, monument, mountain, park, snow, street, and water.
- **Spatial evaluation:** Geographic blocking using 5° × 5° latitude–longitude blocks.
- **Neural training:** AdamW, learning rate of 0.001, weight decay of 0.0001, batch size of 512, and up to 60 epochs, with five random seeds.
- **Classical baseline:** Scikit-learn `HistGradientBoostingClassifier` evaluated using the same spatial train/test indices as the neural experiments.

See the notebooks and paper for the complete experimental configurations and evaluation procedures.

## Main Finding

The study demonstrates why weak neural fusion performance alone is insufficient to conclude that metadata contains no useful predictive information. In the scene-classification task, the matched-split classical metadata-only baseline extracted more predictive information than the neural metadata branch, while the neural fusion improvement was small and not statistically significant in the reported principal comparison.

These findings distinguish metadata informativeness from the ability of a particular fusion architecture to exploit it. They do not establish that metadata necessarily contributes complementary information beyond image features.
